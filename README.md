- security-incident-manager
- cyber-security-utilities

<h2 align="center">Descriptions of Each Task</h2>
<h3 align="center">Security Tool</h3>
<p align="center">This program will present the user with a security menu containing 3 main options. The first allows the user to run a security event counter. The second allows the user to run a brute-force simulation. The third allows the user to run a login authentication simulation</p>

<h3 align="center">Security Event Logger</h3>
<p align="center">This program will record security related activities. The program will ask for a username and password from the user until the correct credentials are entered. It will record a log of each try and then print all logs at the end</p>

<h3 align="center">IP Address Validator</h3>
<p align="center">This program will do a basic format check. The program will ask for a IP address and then it will validate this IP address using a function</p>

<h3 align="center">Security Incident Manager</h3>
<p align="center">This program will store and update information about a security incident using dictionaries</p>

<h3 align="center">Cyber Security Utilities</h3>
<p align="center">This program will use a small collection of reusable cyber security functions to validate an IP address, validate a password and randomly generate a strong password</p>
