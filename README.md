<h1 align="center">Cyber Security Utilities</h1>
<p align="center">This program will use a small collection of reusable cyber security functions to validate an IP address, validate a password and randomly generate a strong password</p>

<h2 align="center">How to Run the Program</h2>
<p align="center">The program will ask you to enter a IP address and a password. It will then tell you if the IP and password is valid or not. If the password is not a minimum of 8 characters and doesn't include at least one letter, number or symbol it is considered not valid. When the password is considered not valid the program will tell you the password is weak and then present you with a randomly generated strong password for you to use</p>
